## 1 · Rules
**Flow:** `docket` 75 s → (no charges ⇒ "Court adjourned", nobody jailed ⇒ `new_day`) → `against` 30 s → `defence` 30 s → `verdict` 45 s → `settlement` → `new_day`.
**Can act** (press, back, vote; prosecutors also file exhibits and object to counterproof) = alive, not in prison, not in hospital. **Jury** = every actor who isn't a prosecutor, the defendant or the witness: talks and votes only, never files or objects. **Witness** = any living player (hospital/prison OK). **Defence actions** (file counterproof, object to a prosecution exhibit) = defendant + accepted witness only, hospital/prison OK.

**Docket.** *Press* 1×/player/day: `vice` (always) · `murder` (victim died today, from `kill_log`; return ids only — the log is secret) · `false_witness` (defendant sent the presser a DM today). Defendant: alive, not in prison, not self. Stake 25/50/75/100. Pressing an identical charge (defendant + kind + victim) backs it instead and doesn't use the press. *Back* in +25 steps, cap 100 per player per charge (press stake counts), never on a charge against yourself, **no withdrawals**. Everything public, live (charge, pot, every backer + amount, feed).
**Close:** per-defendant total = all backing on all charges against them. **Highest total is the only defendant** (tie → more distinct backers → earliest press). Banner shows their largest charge (tie: vice > murder > false_witness) plus the others. **Every presser/backer of any charge against them is a prosecutor; all other charges are refunded at close.**

**Trial (one).** Majority-advance per half (`useMajorityAdvance`, 10 s). Every new exhibit or counterproof adds 10 s to the current half, max +30 s per trial.
- **Exhibit** (`P1, P2…`): `against` half only; **prosecutors only** (must also be able to act); 1 per prosecutor; **50 → pot**. May be forged.
- **Witness:** defendant calls 1 player with no stake (not a prosecutor), either half; 15 s to accept/refuse, half held open while pending; no answer = refused. Public.
- **Counterproof** (`D1, D2`): `defence` half; the defendant and the accepted witness may **each file 1** (max 2 per trial); 50 (filer's own stake, not in pot).
- **Exhibit kinds (v1):** `quiz_peek{day,target,camp}` · `quiz_hint{day,a,b,form:'opposite'|'at_least_one',camp?}` · `msg_received{day,from,payload}` · `msg_sent{day,to,payload}`. Composer pre-fills the filer's genuine data; editing = forgery (private warning to filer only). Only *plausible* filings allowed: quiz kind must match the filer's `quiz_log` for that day; a msg needs a DM between those two that day. Genuineness computed at filing, stored **locked**.
- **Objections** (50, each piece once, ruling instantly public as `FORGED`/`UPHELD` — never the underlying truth):

| Target | Who may object | Forged | Genuine |
|---|---|---|---|
| Prosecution exhibit (either half) | **defendant or accepted witness only** | objector gets **100** (own 50 + filer's 50); exhibit struck, its 50 leaves the pot | objector's 50 → filer; marked upheld |
| Counterproof D1/D2 (**1 objection each**) | **prosecutors only** | objector gets **100** (own 50 + filer's 50); struck | objector's 50 → **defendant** (whoever filed it); marked upheld |

- Only prosecutors file exhibits; only the defence files counterproof. Each side may only challenge the other's proof; the jury can't file or object.

**Verdict** (all-voted or timer; no majority-advance). Voters = all actors except the defendant (jury, prosecutors and witness). **Guilty = `player_secrets.vote = <defendant id>`, Not guilty = `'skip'`, blank = null** — reuse `submit_vote` so Iron Will (×2), Empathy, Truthfulness, Vengeance jailers and the vote-reveal potion keep working. **Guilty ⇔ weighted Guilty > weighted Not guilty and Guilty ≥ 2.** Tie → Love's armed tie-break decides by Love's vote, else Not guilty. No re-vote. Guilty ⇒ **imprisoned**; Not guilty ⇒ **spared**. Wandering Soul ward blocks prison ⇒ everyone refunded.

**Settlement** (inside `resolve_consultation_impl`, after imprisonment). Pot = all backing + standing prosecution exhibits. **Imprisoned:** every prosecutor gets **2×** what they put in (backing + standing exhibits); counterproofs lost. **Spared:** pot split 50/50 defendant/witness (all to defendant if no witness accepted); each standing counterproof back **2×** to its filer. SE floor 0. Show **every player's** payout lines publicly (all derived from public data) + own total highlighted. Update reputation counters.

**Visibility.** Public: docket, stakes, exhibits + status, witness call/answer, objections + rulings, Guilty/Not-guilty counts after close, outcome, payouts, reputation, **court record** (per player per day: quiz kind `points|hint|peek`, DM pairs → / ↔, dead marked †, past trials). Private: own SE; filer's forgery warning; witness prompt; genuineness of unchallenged exhibits (filer + dead only); individual votes (dead + vote-reveal holder, as today). Never shown: quiz targets/results, message text (unless filed), roles, votes.
